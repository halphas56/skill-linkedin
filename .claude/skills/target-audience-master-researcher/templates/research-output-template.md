# Target Audience Research Report — Output Template

**The delivery contract.** This is the shape the skill produces for a full engagement. Section numbers are stable; do not renumber.

**Language.** Produce the whole report in the language of the brief. For a Russian brief, formulate natively — Russian market conventions, Russian framework names (5W, лестница Ханта, ABCDX), Russian verbatim quotes. Never translate a positioning line word-for-word.

**Evidence marking is mandatory throughout:**

| Marker | Meaning |
|---|---|
| `[E]` | Evidence — traceable to a named source, interview, dataset or observable artefact |
| `[S]` | Synthesis — a conclusion drawn across sources; defensible, not citable |
| `[A]` | Assumption — no evidence found; stated so it can be attacked |

---

## §0 — The Delivery Header — required on every output, in every mode

**Why this exists.** Testing established that the skill's guardrails "depend on being remembered, and a guardrail that depends on being remembered fails silently." That diagnosis was half wrong. `[S]`

The guardrails that *survive* — evidence profile, assumption count, gates — all live in **templates**. The ones that kept getting skipped — the premise audit, the unwelcome finding — lived **only in prose**. The difference is not importance. It is that **a blank in a form is visible and a forgotten paragraph is not.**

> **A rule in prose must be remembered. A rule in a form must be filled or visibly skipped.**

This block moves every remaining prose-only guardrail into structure. **It goes at the top of every deliverable — FULL, VERDICT, COMPARE, DIRECT, RESEARCH PLAN, AVATAR, all of them.**

```
─────────────────────────────────────────────────────────────
 DELIVERY HEADER
─────────────────────────────────────────────────────────────
 Mode: ________  Regime: focus/reach/mixed  Pass: 4h/1d/1w/1m

 PREMISE AUDIT — the client's claims, levelled
 | Client's claim | Level needed | Level arrived | Gap? |
 |----------------|--------------|---------------|------|
 |                |              |               |      |
 → none found? write "brief levelled, no unevidenced claims"

 EVIDENCE
 L0:__ L1:__ L2:__ L3:__ L4:__ L5:__ L6:__
 Independent source TYPES: __        Triangulated: yes/no
 Primary recommendation sits at: L__
   ⚠ below L4 → this is a research plan. Say so in line one.
 Assumptions: __ / __

 GATES: PASS  /  FAIL on ______________________

 THE THREE THAT GET SKIPPED
 Anti-audience:      ______________________________________
 Trade-off accepted: ______________________________________
 Unwelcome finding:  ______________________________________
─────────────────────────────────────────────────────────────
```

### The compressed form — for VERDICT, DIRECT and any answer under a page

A one-page answer still carries the header. **It just carries it as one line:**

```
[mode · regime · primary rec at L__ · gates PASS/FAIL · __ assumptions ·
 premise: levelled/N gaps · refusing: ______ · trade-off: ______]
```

**A short answer is not exempt.** It is the shape most likely to skip the checks, because there is no obvious place to put them.

### Why these three, specifically

| Field | Why it is in the header rather than the body |
|---|---|
| **Premise audit** | The most recently added guardrail and the one with **zero template presence**. It is also the one whose absence is invisible — nobody notices a challenge that was never made |
| **Anti-audience** | An audience is defined by the refusal. A deliverable with no refusal has not made a choice, however long it runs |
| **Unwelcome finding** | *"A report that flatters every prior belief has agreed, not researched."* This was a rule in the manual with no artefact anywhere. **A blank here is a finding about the analysis** |

### The rule for the blanks

**Never delete a row to make the header look complete.** An honest blank is a finding:

- Premise audit empty → *"brief levelled, no unevidenced claims found"*
- Anti-audience empty → *"could not name one at this evidence level"* — and that is itself worth reporting
- Unwelcome finding empty → **look again.** If a full pass genuinely produced nothing the client will dislike, either the client was already right about everything or the pass was shallow. Say which.

## Choosing the output shape

Not every request needs fourteen sections. Match the shape to the ask:

| Request | Shape |
|---|---|
| "Find our target audience" / full research | **FULL** — all 14 sections |
| "Which of these two segments?" | **COMPARE** — §1, §4, §6, §7, §13, §14 |
| "Where do we find them?" | **HABITAT** — §1, §9, §10, §11, §14 |
| "Can we get them for free?" | **FREE** — §1, §9, §10, §13, §14 |
| "Build our ICP / personas" | **PROFILE** — §1, §5 (expanded), §12, §14 |
| "Is this audience any good?" | **VERDICT** — §2, §6, §7, §14 — one page, direct answer first |
| "Find a non-obvious audience" | **UNEXPECTED** — §1, §3, §4, §8, §13, §14 |

Padding a verdict into fourteen sections is a failure, not thoroughness.

## 5. Detailed Segment Analysis

*Repeat for each of the top 5–8. Under 5 segments, do all of them.*

### Segment [N]: [name]

**Obvious or unexpected:** ______ · **Generator:** ______ · **Evidence strength:** [E] / [S] / [A]

- **Description.** Who they are, in a sentence containing a **who**, a **when** and a **where**.
- **Problem and pain.** In their words, verbatim where available. Quantified if they quantified it.
- **Desired outcome.** The after-state, as they describe it.
- **Buying triggers.** The dated events that start the search.
- **Existing alternatives.** Including "nothing" and "a spreadsheet." Name what you actually lose to.
- **Ability to pay.** With the evidence — existing budget line, comparable spend, salary of a related hire.
- **Willingness to pay.** Separately from ability. Category norms, price corridor if known.
- **Where they live.** Named venues, online and offline, with sizes and entry routes.
- **Best free acquisition channels.** With required asset and time-to-signal.
- **Best paid acquisition channels.** With targeting parameters that actually exist on the platform.
- **Best content angles.** Derived from their repeat questions, not brainstormed.
- **Best outreach angle.** The specific observable fact you would reference.
- **Trust requirements.** What proof this segment accepts. What you would need to build.
- **Objections.** From the four forces — Anxiety (fear of the new) and Habit (attachment to the current mess).
- **Positioning hook.** One line. Must fail the swap test.
- **Why obvious or unexpected.** If unexpected: which generator found it, and what evidence exists that it is real.
- **Risks.** Named, with likelihood.

## 6. Audience Scoring Matrix

Full matrix per `scoring-matrix-template.md`. Report **four columns per segment, always together** — a bare score is astrology with decimals.

| Segment | TAS | Gates | Evidence | Assumptions | Verdict |
|---|---|---|---|---|---|
| | _._ /5.0 | PASS / FAIL on ___ | L_ | __/45 | |

**Preset used (diagnostic layer):** ______ · **Weight adjustments and why:** ______

**Reading rules:**
- **Gate failures are stated on the same line as the score.** A 4.5 with a failed gate is a disqualification, not a recommendation.
- **A difference under 0.3 is not a difference.** Break ties with an experiment, not with more argument.
- **A high TAS at `L2` loses to a lower TAS at `L5`.** One is a hope; the other is real.
- **Uniform excellence deserves suspicion.** Real segments have trade-offs; a segment scoring high everywhere is usually scoring on assumptions.

**Show the eleven TAS variables for at least the top segment**, each with its source, so the total can be audited rather than trusted.

## 13. Validation Plan

5–10 experiments, ordered by evidence-per-cost.

| # | Hypothesis | Method | Channel | Success metric | Minimum evidence | Cost | Speed | Risk |
|---|---|---|---|---|---|---|---|---|
| 1 | | | | | | | | |

**Rules for this section:**
- Match the instrument to the unknown: demand → fake door · market or message → smoke test · delivery or value capture → concierge MVP.
- Success metrics must be **costly actions** — email, booking, deposit, purchase. Never clicks, likes or "interest."
- **Declare in advance what result would change the recommendation.** An experiment with no falsifying outcome is a demonstration, not a test.
- Ethical floor: never take money or personal data you cannot honour.
