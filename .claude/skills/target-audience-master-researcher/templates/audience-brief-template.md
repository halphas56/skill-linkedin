# Audience Brief — Intake Template

**For the client to fill in before an engagement, or for the researcher to fill in during intake.**

---

## How to use this

**You do not need to complete it.** The skill is built to run on partial input and mark its assumptions. A brief with five fields filled honestly beats one with thirty filled speculatively.

Two rules:

1. **Write "don't know" rather than guessing.** A marked gap gets researched. A confident guess gets built on.
2. **Where you have evidence, name it.** `"Clients pay ₽80–150k/month"` is worth more than `"mid-market pricing"`, and `"3 of our last 5 clients came from one Telegram chat"` is worth more than both.

Fields marked **★** are the ones that change the answer most. If you only fill five, fill those.

## Researcher's intake checklist

Complete before starting the analysis. Anything unfilled becomes a stated assumption in the output, not a blocker.

- [ ] Business model identified → **scoring preset selected:** ______________
- [ ] Regime identified → **focus / reach**
- [ ] Price point known or estimated → **max viable CAC:** ______________
- [ ] Language and geography confirmed → **output language:** ______________
- [ ] B2B? → buying-group mapping required
- [ ] Existing customers? → ABCDX analysis available
- [ ] Budget = 0? → free-acquisition feasibility becomes the gating question
- [ ] Founder hours/week: ______ → **free channels viable? yes / no**
- [ ] Goal identified → determines whether output prioritises speed or durability
- [ ] **Assumptions to state in the output:** ______________________________

**If fewer than five ★ fields are answered:** ask for those five, then proceed regardless of the response. Do not block on intake. State assumptions and deliver.
