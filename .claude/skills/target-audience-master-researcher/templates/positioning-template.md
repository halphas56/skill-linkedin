# Positioning Template — Built From the Chosen Audience

**Prerequisite.** Do not fill this in before a segment is chosen and scored. Positioning derived from an unvalidated audience is fiction with formatting.

**The order is non-negotiable.** Competitive alternatives → unique attributes → differentiated value → **best-fit customers** → category. Run backwards, it produces audience flattery that commits to nothing.

> *"Positioning defines how your product is a leader at delivering something that a well-defined set of customers cares a lot about."* — April Dunford

---

### 0.5 Market category

## Part 3 — Quality gates

Fail any one and the positioning is not ready.

- [ ] **Swap test** — substituting the top competitor's name makes it read false
- [ ] **Circumstance present** — a *when*, not just a *who*
- [ ] **Real alternative named** — including "nothing," if that is the truth
- [ ] **One claim, not two** — "fastest and safest" claims nothing; pick one
- [ ] **Their vocabulary, not yours** — traceable to research verbatim
- [ ] **Proof is real or marked** — every gap flagged `[PROOF NEEDED]`, nothing invented
- [ ] **Trade-off named** — what you give up, and who you are refusing
- [ ] **Category answers "what is a ___?" in one clause**
- [ ] **A competitor could not adopt this without breaking their own positioning**
- [ ] **Testable** — you can name the experiment that would falsify it
